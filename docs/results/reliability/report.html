Run it yourself

git clone https://github.com/leonbede7/intake-eval.git
cd intake-eval
npm run reliability

Requires Node.js 24 or later. The command starts an ephemeral loopback HTTP server, injects the faults and writes JSON and HTML reports under local-data/reliability. No dependency installation is needed for this command.

AI-authored synthetic faults served by a local HTTP server. Real fetch, provider parsing and V2 validation are executed. No model is called and no API key is read. These results measure specified failure behavior, not model accuracy or production reliability.

Machine-readable results

Policy: V2. This is an AI-assisted portfolio prototype. A passing contract check is not an uptime guarantee or a model benchmark.
