Words are not intent

“I do not need a refund” contains a trigger word. V1 routes by English keywords. V2 asks for an explicit reason and a supporting quote.

Urgency is a different question

A routine refund can be normal priority and still require financial review. The updated contract keeps those decisions separate.

C

Keep the failures visible

Model output, provisional labels, prompt hashes and rejected responses stay available for inspection. A higher match count is not proof of safety.

About this project.

I work on AI-assisted products and automation, informed by hands-on dealership operations. This project explores one practical question: what has to happen between an AI response and a business action?

The implementation, examples and documentation were built with AI assistance. My portfolio describes the scope and evidence openly. This is a prototype with synthetic data, not a production support system.
